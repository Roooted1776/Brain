    How this page handles data

    Brain does not watch other apps or connect to external data sources. It saves prompts sent through this page, replies received from enabled real models, and notes you add yourself. Replies are labeled with their provider and model, but are not independently verified. Unconnected bots stay silent; failed calls never become scripted replies. Incognito prompts are not saved.

    The brain is an extrusion of the traced side-profile outline. Only that 2D contour is measured; the displayed depth is illustrative, not a 3D scan reconstruction. The page uses no bundled demo facts or sample sources. Memory nodes are labeled and colored by type; linked session memories form a web.

      Privacy

      • Brain stores only prompts sent here, real model replies received, and notes you add.
      • Incognito sessions are skipped completely.
      • Common password and key patterns are filtered out before saving. This is a best-effort filter, not a guarantee, so do not paste real secrets.
      • No model calls happen until Live AI is enabled and you submit a prompt.
      • No web search or Perplexity connection is implemented.
