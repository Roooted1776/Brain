# mri/ — the shape of Brain

The memory graph is drawn inside the outline of Max's own brain, traced by hand from one side-view MRI slice.

- `brain-outline.json` — the same numbers that sit in the `BRAIN` block of `index.html` (outline, folds, where each kind of memory lives, hub position). The page keeps its own copy so it still opens by double-click; if you change one, change the other.

**Privacy rule: scan files never go in this repo.** No DICOM files, no `DICOMDIR`, no pictures of the scan (a side view shows the face), no names, dates or IDs. Only the traced numbers are kept. The original disc stays on Max's computer. The outline is decorative, not medical.
